COS 106 STUDENT PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Navigate through Home, About, Projects, Planner and Contact.

FILES
- index.html, about.html, projects.html, planner.html, contact.html: five website pages
- css/style.css: external responsive stylesheet
- js/script.js: navigation, academic planner and contact form validation
- assets/: add your own profile photograph here if desired

IMPORTANT PERSONALISATION
- Check all profile details and edit anything that is inaccurate.
- The homepage currently uses an OM initials graphic as a photograph placeholder. Replace it with your own photograph before final submission if possible.
- Project entries are sample portfolio descriptions. Keep only work you can explain and accurately describe.
- Contact form validation is client-side only and does not send messages to a server.
- Planner tasks are saved in the browser's local storage.

PUBLISHING
Upload the website files (not the ZIP file) to a GitHub repository. In GitHub, open Settings > Pages, choose Deploy from a branch, select main and /(root), then save. Wait for the published URL.
